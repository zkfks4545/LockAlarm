# LockAlarm 사용 안내

현재 GitHub 배포본은 `v0.15.24` 시험판입니다. 설치 전에는 [README의 다운로드·주의사항](../README.md#다운로드)과 [설치 문제 확인](INSTALLATION.md)을 먼저 읽어 주세요. 중요한 알람에 사용하기 전에는 본인 기기에서 동작을 검증해야 합니다. 같은 버전의 APK가 교체됐으므로 이전에 받은 파일은 새 해시를 확인해 주세요.

## 처음 실행할 때

앱은 필수 접근 설정 화면을 먼저 표시합니다. 모든 접근을 완료하기 전에는 새 알람 추가·편집·전체 화면 테스트가 잠깁니다.

- `다른 앱 위 전체화면 표시` 등 알람 표시를 위한 접근을 설정합니다.
- `권한 설정 없이 기존 목록만 보기`를 선택하면 저장된 알람과 최근 콘텐츠만 열람할 수 있습니다.
- 설정 화면에서 돌아오면 누락된 접근 상태가 즉시 갱신됩니다.

## 알람 사용 흐름

### 알람 만들기

시각을 숫자로 입력하거나 시계 화면에서 선택합니다. 새 알람은 오늘 날짜로 시작하고 숫자 입력 중에는 날짜가 바뀌지 않습니다. 알람을 활성화할 때 자동 계산된 날짜가 오래되었어도 오늘의 설정 시각이 남아 있으면 오늘로 예약하며, 오늘 시각이 이미 지났을 때만 다음 날로 자동 변경합니다. 사용자가 직접 선택한 미래 날짜는 유지합니다. 알람 카드는 활성 여부와 관계없이 `localTimeMinutes` 기준으로 이른 시각부터 정렬됩니다.

알람마다 다음 항목을 설정할 수 있습니다.

- 알람 이름과 활성화 여부
- 단발, 요일별 반복 또는 매일 반복
- 화면 잠금 타이머(로컬 미디어는 확인된 길이까지, YouTube는 미확인 시 임시 5분·미리보기 재생으로 길이를 확인하면 그 길이까지, 그 밖의 길이 미확인 콘텐츠는 60초까지)
- 로컬 미디어 또는 YouTube 주소
- 별도 음악, 밝기, 미디어 음량, 종료 시 복원 정책

### 알람이 울릴 때

알람 화면은 현재 `HH:mm`, 알람 이름, 타이머와 조작부를 미디어 위에 표시합니다. 화면을 잠그거나 홈·최근 앱으로 이동해도 포그라운드 서비스가 세션을 유지하고, 화면을 다시 켜면 잠금 상태에 맞는 알람 화면을 복구합니다. 이미 다른 알람이 울리고 있거나 스누즈 중이면 새 알람이 기존 세션을 선점하고 즉시 자신의 콘텐츠를 시작합니다.

종료 타이머가 켜져 있으면 타이머가 끝날 때까지 종료·위로 밀기·스누즈·미디어 조작이 잠깁니다. 타이머가 끝나면 다음 조작을 사용할 수 있습니다.

- 하단 중앙 한 행: 5분 스누즈와 `알람끄기` 버튼을 바로 옆에 배치하며, 스누즈 재울림에서도 두 버튼을 계속 표시
- 위로 160dp 이상 밀기: 종료

물리 전원 버튼과 Android의 강제 종료는 일반 앱에서 차단할 수 없습니다.

## 미디어 동작

### 로컬 파일

파일 선택 화면에서 이미지·GIF·WebP·영상·음악 탭을 사용할 수 있습니다. 최근순·이름순 정렬, 파일명 검색, 음악 미리듣기를 지원합니다.

Android 사진 선택기와 MediaStore에 없는 파일은 `직접 찾아보기`로 선택할 수 있습니다. 파일을 앱에 복사하지 않고 URI만 저장하므로 저장 공간을 불필요하게 사용하지 않습니다.

소리는 다음 순서로 선택됩니다.

1. 별도 음악 파일
2. 영상 자체 소리
3. 기기 기본 알람음

로컬 음악·오디오 영상·기본 알람 URI는 개별 재생 볼륨을 10%에서 시작해 30초 동안 250ms 간격으로 100%까지 올립니다. 기기의 `STREAM_MUSIC` 음량은 알람 시작 시 지정한 초기값을 한 번 적용합니다. 울리는 중 사용자가 목표보다 낮춘 경우에만 서비스가 2초마다 최대 음량의 5%(최소 1단계)씩 목표까지 올리며, 목표보다 높은 사용자 음량은 낮추지 않습니다. 스누즈 대기·선점·해제·취소·서비스 종료 시 감시를 중지합니다. `ToneGenerator` 대체음도 기기 음량 복원 감시의 적용을 받습니다.

### YouTube

알람 편집 화면에 유효한 YouTube URL을 입력하면 공식 썸네일과 수동 미리보기 재생 버튼이 표시됩니다. URL 입력만으로는 재생하거나 길이를 확인하지 않습니다. 길이 확인 전 화면 잠금 타이머의 최대값은 임시 5분입니다. 미리보기를 한 번 재생하면 공식 IFrame 플레이어가 영상 길이를 불러오는 대로 타이머 최대값을 그 길이로 바꿉니다. 끝까지 시청할 필요는 없으며 길이가 표시되면 미리보기를 닫을 수 있습니다. 확인한 길이는 같은 영상 ID에 한해 앱 실행 중 임시 재사용하고, 알람을 저장하면 그 알람의 길이는 재시작 후에도 유지됩니다. 실제 알람 화면의 재생 표면은 표시 전용이며 YouTube 자체의 재생·일시정지·탐색·전체화면·키보드 조작을 할 수 없습니다.

- 일반 영상은 가로, Shorts는 세로로 시작합니다.
- 재생 준비 후 기기 방향 센서에 따라 회전합니다.
- 네트워크·자동재생 제한은 공식 YouTube 플레이어 정책을 따르며, 알람 화면의 스누즈·알람끄기만 앱의 native 동작으로 제공합니다.
- 빈 URL이나 지원하지 않는 주소는 안내로 표시합니다.
- 다운로드·캐싱·MP3 추출은 지원하지 않습니다.

홈 화면에서는 YouTube를 재생하지 않고 공식 썸네일만 표시합니다.

## 화면과 상태 보존

메인 화면은 큰 시간과 토글 중심의 카드 대시보드입니다.

- 좁은 화면: 세로 목록과 하단 내비게이션
- 넓은 화면: 좌측 레일과 2열 카드
- 화면 회전·Galaxy Fold 접기/펼치기: 재생 화면을 새로 만들지 않음
- 잠금 화면과 오버레이 사이 이동: 세션의 마지막 로컬·YouTube 재생 위치에서 이어보기 시도
- 스톱워치 옆 타이머 탭: 시작·일시정지·계속·초기화

타이머는 `SystemClock` 기준으로 계산하므로 화면을 이동하거나 회전해도 진행 상태를 유지합니다. 울림 중 상태의 기준은 포그라운드 서비스와 저장된 세션 상태입니다.
