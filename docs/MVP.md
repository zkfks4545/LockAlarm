# 이전 MVP 구현 메모

> 이 문서는 최초 세로 슬라이스 구현 당시의 기록이다. 현재 제품 동작의 원본 계약은 `specs/001-core-alarm/spec.md`이며, 두 문서가 충돌하면 해당 Living Spec을 따른다.

## 고정 범위

- 단일 1회성 알람을 `AlarmManager.setAlarmClock()`으로 정확히 예약한다.
- 알람 수신 즉시 사용자에게 보이는 포그라운드 서비스를 시작한다.
- 높은 중요도의 알람 알림과 full-screen intent로 잠금 화면 위 알람 Activity를 연다.
- 알람 시작 시 기존 밝기 모드·밝기·미디어 음량을 영속 저장한다.
- 시작 시 밝기는 수동 모드의 지정값, `STREAM_MUSIC`은 지정값으로 각각 한 번만 변경한다. 이후 값은 감시하거나 재적용하지 않는다.
- 해제 시 `원래 값 복원` 또는 `현재 값 유지` 정책을 적용한다.
- 로컬 모드는 선택한 이미지/GIF/무음 영상을 전체화면에 표시하고, 기기 기본 알람음을 미디어 스트림으로 반복 재생한다.
- 해제 버튼은 3~30초의 설정 시간이 지난 뒤 표시한다.
- 홈으로 이동해도 로컬 음원은 포그라운드 서비스에서 계속 재생한다.
- YouTube 모드는 URL을 검증한 뒤 YouTube 앱(없으면 일반 URL 처리 앱)으로 넘긴다. 자체 스트리밍·다운로드·MP3 추출은 하지 않는다.
- SAF `OpenDocument`로 선택한 시각 콘텐츠의 읽기 URI 권한을 영속 보관한다.
- 재부팅, 앱 업데이트, 정확 알람 권한 재승인 후 아직 미래인 활성 알람을 재등록한다.

## 의도적으로 다음 단계로 미룬 범위

- 복수 알람, 요일 반복, 공휴일/스누즈
- 앱에 번들된 복수 음원과 사용자 음원 선택
- 알람 목록·편집·삭제 화면 및 Room 데이터베이스
- 사용자가 실행 중 값을 바꾼 경우에만 복원하지 않는 조건부 복원 정책
- 제조사별 절전 예외 안내, 실제 기기 매트릭스 테스트
- UI 테스트, 서비스/Receiver 계측 테스트, 프로세스 강제 종료 복구 시나리오

## 구조

첫 MVP는 Gradle 모듈을 `:app` 하나로 유지하고 패키지 경계로 역할을 분리한다.

```text
app
├─ model       AlarmSpec과 정책 enum
├─ data        단일 알람 영속 저장
├─ alarm       예약, Receiver, 세션, 기기 상태, FGS, 전체화면 Activity
├─ ui          Compose 테마와 로컬 시각 콘텐츠 렌더링
└─ youtube     외부 YouTube 앱 이관만 담당
```

복수 알람과 반복 규칙을 도입할 때 `model/domain`, `storage(Room)`, `alarm-runtime`, `app-ui` 모듈 분리를 검토한다. 지금 미리 다중 모듈화하면 경계보다 설정 비용이 더 크므로 보류한다.

## 상태 전이

```text
저장/예약
  → AlarmManager 수신
  → FGS + full-screen notification
  → 이전 기기 상태 저장
  → 밝기/미디어 음량 1회 적용
  → 로컬 재생 또는 YouTube 이관
  → 사용자 해제
  → 정책에 따른 복원/유지
  → FGS 종료 + 알람 비활성화
```

## 플랫폼 주의점

- Android 12+에서는 정확 알람 특별 접근이 없으면 예약하지 않는다.
- Android 13+ 알림 권한, Android 14+ full-screen intent 특별 접근을 첫 화면에서 안내한다.
- `WRITE_SETTINGS`는 일반 런타임 권한이 아니므로 시스템 설정 화면에서 사용자가 직접 허용한다.
- Android 14+에서 로컬 재생은 `mediaPlayback`, YouTube 이관 중 알람 수명 관리는 `specialUse` 포그라운드 서비스 유형을 사용한다.
- full-screen intent는 잠긴 기기에서 Activity를 열며, 잠금 해제 상태에서는 시스템 정책에 따라 확장 알림으로 보일 수 있다.
- 제조사 절전 정책은 표준 API보다 알람 전달을 더 제한할 수 있으므로 삼성 실제 기기 검증이 필요하다.
