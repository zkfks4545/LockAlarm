# APK 설치 문제 확인

현재 GitHub의 [`v0.15.24` Pre-release](https://github.com/zkfks4545/LockAlarm/releases/tag/v0.15.24)는 실제 기기 알람 동작 검증을 마치지 않은 시험판입니다. 휴대폰에 이전 LockAlarm이 설치되어 있다면 **기존 앱을 먼저 삭제하지 마세요.** 이 앱은 클라우드 백업과 기기 간 데이터 전송을 사용하지 않으며, 알람·설정을 파일로 내보내는 기능도 없습니다. 삭제하면 로컬 데이터가 사라질 수 있습니다.

## 현재 확인된 내용

- 현재 공개된 [`LockAlarm-v0.15.24.apk`](https://github.com/zkfks4545/LockAlarm/releases/download/v0.15.24/LockAlarm-v0.15.24.apk)는 로컬 정식 서명 APK와 SHA-256 `6C25ED0D65DFD09F1612E8375C0F24042DA3D96DF2371CCA23E67BE3C8E097CD`으로 일치합니다. 서명 인증서 SHA-256은 이전 v0.15.22·v0.15.23 정식 배포본과 동일한 `442090DDA070A1F970CEE370A0469DE0E1A560CA0668F71FA984EF0B9DB491D8`입니다. 2026-10-06에 같은 버전의 자산을 다시 교체했으므로 이전에 받은 파일은 해시를 확인해 주세요.
- 2026-10-06 v0.15.24에 처음 첨부된 `routine-alarm-integrated-final-v15.24-debug.apk`는 Android Debug 인증서 SHA-256 `1E5C10DF0DF1E6147EA4A77377DE3E0D33486899419FDE5CD6FCFFF17CF4E7E4`로 서명돼 있었습니다. 이 잘못된 자산은 제거했으며, 이미 다운로드한 파일은 정식 APK로 다시 받아야 합니다.
- 이번 교체본은 기존 정식 v0.15.24와 `versionCode 39`가 같습니다. 새 버전 번호가 아니므로 자동 업데이트 알림을 기대하지 말고 새 APK를 직접 받아 설치해야 합니다. 같은 서명키를 사용하지만, 특정 기기의 제자리 설치 성공은 아직 검증하지 않았습니다. 설치 문제를 해결하려고 기존 앱부터 삭제하지 마세요.
- 사용자가 본 Play Protect 경고와, 그 뒤에 나타난 “앱이 설치되지 않았습니다”는 구별해서 확인해야 합니다. 경고 화면만으로 설치 실패의 정확한 원인을 알 수 없습니다.

## 현재 가장 유력한 가설

기기에 **개발용 인증서로 서명된 같은 패키지**가 설치되어 있다면 정식 인증서 APK로 덮어쓰기 업데이트할 수 없습니다. 초기 v0.15.24 개발용 자산을 설치한 기기도 이에 해당합니다. 다만 개별 기기의 설치 실패는 버전 코드 다운그레이드, 저장 공간 부족, 다운로드 문제, 다른 사용자 프로필의 설치본 등 다른 원인일 수 있으므로 오류 코드를 확인해야 합니다.

## 지금 할 일

1. 기존 LockAlarm을 **삭제하거나 앱 데이터를 지우지 말고**, 사용 중인 알람을 그대로 유지합니다. 중요한 알람은 별도의 신뢰할 수 있는 수단도 함께 사용하세요.
2. 휴대폰에서 설치를 시도한 APK의 파일 이름과 다운로드 출처를 확인합니다. 설치 파일이 남아 있다면 보존해 주세요. 파일 이름만으로 실제 설치본의 서명을 증명할 수는 없습니다.
3. 나중에 USB 디버깅 연결이 가능해지면 기존 패키지·버전·서명을 읽기 전용으로 확인하고, 설치 실패 시점의 Android 로그에서 오류 코드를 확인합니다. 로그를 지우거나 앱을 제거할 필요는 없습니다.
4. 원인이 서명 충돌로 확인되면 기존 데이터 보존 방법을 먼저 결정해야 합니다. 현재 앱에는 개발용 서명에서 정식 서명으로 알람 데이터를 자동 이전하는 기능이 없습니다. 삭제 후 재설치는 데이터 유실을 감수하는 별도 결정입니다.

공개 파일과 로컬 파일의 서명·해시 확인 방법은 [배포 안내](RELEASE_GUIDE.md)를 참고하세요. Android의 동일 인증서 업데이트 요구사항은 [공식 앱 서명 문서](https://developer.android.com/studio/publish/app-signing)에 설명되어 있습니다.
