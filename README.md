# LockAlarm (Android MVP)

정해진 시각에 밝기와 미디어 음량을 초기값으로 한 번 적용하고, 잠금 화면 또는 다른 앱 위 전체화면에서 영상 자체 소리·별도 로컬 음악·공식 YouTube 임베디드 플레이어를 재생하는 개인용 Android 알람 앱입니다.

계정과 서버 없이 동작합니다. 실행·해제 같은 행동 로그는 저장하지 않습니다. 대신 알람에 실제로 사용한 로컬 파일과 YouTube 주소만 최근 30개까지 기기에 보관합니다. 로컬 파일은 앱에서 열람하고 YouTube 주소는 복사할 수 있습니다.

각 알람 카드의 활성화와 별도 미리보기 스위치는 독립적으로 동작하고 미리보기 상태는 알람별로 저장됩니다. 카드의 로컬 영상은 소리를 끈 상태로 여러 개를 동시에 재생할 수 있으며, 각 카드는 고정된 경계 안에서 원본 비율을 유지하고 `CENTER_CROP`처럼 넘치는 부분만 잘라 표시합니다. 홈 화면의 YouTube는 공식 썸네일만 표시하고 재생하지 않습니다. YouTube IFrame 재생은 실제 알람 울림 화면에서만 사용합니다. 스톱워치 옆 타이머 탭에서는 초 단위 시간을 직접 입력하고 시작·일시정지·계속·초기화를 사용할 수 있습니다. 타이머는 `SystemClock` 기준으로 화면을 이동해도 진행 상태를 유지합니다. 알람 카드는 활성 여부와 무관하게 설정한 시각(`localTimeMinutes`)이 이른 순서로 정렬됩니다.

메인 알람 화면은 큰 시간과 토글을 중심으로 한 반응형 카드 대시보드로 표시됩니다. 좁은 화면의 세로 목록·하단 내비게이션과 넓은 화면의 좌측 레일·2열 카드에 대응하며, 상단 버튼에서 다크·라이트 테마를 바꾸고 선택을 유지합니다.

현재 버전과 패치별 변경사항은 [CHANGELOG.md](CHANGELOG.md)에서 확인할 수 있습니다.

현재 앱 표시 이름은 **LockAlarm**이며 구현 버전은 **0.15.7**입니다. 1.0.0 전까지 앱 내부 버전은 `0.xx.xx`, APK 파일명은 `routine-alarm-integrated-final-v15.7-debug.apk`처럼 앞의 `0.`을 뺀 `v15.7` 형식으로 유지합니다.

앱을 처음 실행하면 필수 알람 접근 설정 화면이 먼저 표시됩니다. 모든 접근을 완료하기 전에는 알람 추가·편집·테스트가 잠기며, `권한 설정 없이 기존 목록만 보기`를 선택하면 저장된 알람과 최근 콘텐츠만 열람할 수 있습니다.

## 실행

1. Android Studio에서 이 폴더를 엽니다.
2. JDK 17과 Android SDK 36을 선택합니다.
3. 앱을 실제 기기에 설치하고 첫 화면의 필수 접근(특히 `다른 앱 위 전체화면 표시`)을 허용합니다.
4. 5·10·30·60초 빠른 선택 또는 원하는 초 단위 테스트 간격을 입력해 전체 흐름을 확인합니다. 잠금 화면 동작은 화면을 잠근 뒤 테스트합니다.

알람 시각은 시·분 숫자를 직접 입력하거나 시계 화면에서 고를 수 있습니다. 한 번 알람에서 오늘 이미 지난 시각을 선택하면 자동으로 내일로 변경됩니다. 로컬 영상은 회전 정보를 포함한 실제 영상 규격에 따라 가로 또는 세로 전체화면으로 전환되고, 원본 비율을 유지한 채 화면 안에서 가능한 가장 큰 크기로 표시됩니다. 울림 화면은 로컬 영상·이미지 또는 YouTube를 전체 화면 배경으로 유지하고 공통 화면 위에 현재 `HH:mm`, 알람 이름, 타이머와 조작부를 겹쳐 표시합니다.

화면 잠금 타이머는 알람별로 켜거나 끌 수 있습니다. 켜짐 상태의 대기 시간은 0~60초이며, 꺼짐 상태는 0초로 저장되어 알람 시작 즉시 해제·스누즈·위로 밀기 조작이 가능합니다.

로컬 파일을 선택하면 파일명과 이미지·GIF·영상 미리보기가 표시되고, 음악 파일은 미리듣기가 가능합니다. 소리는 별도 음악 파일이 있으면 그 음악을 사용하고, 없으면 영상 소리, 영상 소리도 없으면 기기 기본 알람음 순서로 자동 결정됩니다.

알람 울림의 로컬 음악·오디오 영상·기본 알람 URI는 `MediaPlayer` 개별 gain을 10%에서 시작해 30초 동안 250ms 간격으로 100%까지 점진적으로 올립니다. 기기 `STREAM_MUSIC` 음량은 시작 시 지정한 초기값을 한 번 적용한 뒤 다시 덮어쓰지 않습니다. `ToneGenerator` 대체음은 재생 장치 제약으로 고정 음량입니다.

알람 편집 화면에서 유효한 YouTube URL을 입력하면 공식 썸네일과 재생 버튼이 표시됩니다. 썸네일이나 버튼을 누르면 편집 화면 안에서만 공식 IFrame 플레이어가 재생되고, `미리보기 닫기`로 썸네일로 돌아갑니다. 빈 URL과 지원하지 않는 주소는 안내로 표시하며 영상 다운로드나 MP3 추출은 하지 않습니다.

파일 선택 화면은 이미지·GIF·WebP·영상·음악 탭을 제공하며, 지원되는 기기 파일만 썸네일 또는 파일명·길이 목록으로 표시합니다. 최근순·이름순 정렬과 파일명 검색을 사용할 수 있고 음악은 선택 전에 미리 들을 수 있습니다. Android 사진 선택기와 MediaStore에 없는 다운로드·클라우드 파일용 `직접 찾아보기`도 함께 제공하며, 선택 결과는 파일 복사 없이 URI만 알람에 저장합니다.

영상 탭은 영상 접근 권한 상태, MediaStore 조회 실패, 실제 조회 0건, 지원 형식이 없는 경우를 서로 다른 안내로 표시합니다. Galaxy의 Downloads·제조사 영상처럼 `Video` 컬렉션에 빠지는 항목은 외부 `Files` 컬렉션도 확인하고, MIME·size·date가 비정상이어도 파일명 확장자로 지원 여부를 판단합니다. Android 14에서 선택한 영상 권한만 있으면 `현재 선택한 영상만 접근 가능하며 전체 목록은 보이지 않습니다`와 `전체 영상 접근 허용` 버튼을 표시합니다. 권한이 없어도 Android 사진 선택기와 직접 찾아보기를 사용할 수 있습니다.

울림 중 뒤로가기는 알람을 닫지 않습니다. 홈이나 최근 앱으로 이동하면 포그라운드 서비스가 다른 앱 위 전체화면 표시를 복구하고, 화면을 껐다 다시 켜면 잠금 상태에 맞는 알람 화면을 다시 표시합니다. 종료 타이머가 진행되는 동안 종료·위 스와이프·스누즈·YouTube/로컬 미디어 조작을 모두 차단하고 하단에 잠금 안내와 남은 시간을 표시합니다. 타이머 완료 뒤 하단 좌측 5분 스누즈(최초 울림 1회)와 우측 큰 X, 160dp 이상 위 스와이프 종료를 활성화합니다. 물리 전원 버튼과 Android의 강제 종료 자체는 일반 앱에서 차단할 수 없습니다.

YouTube 일반 영상은 가로, Shorts는 세로로 시작하고 재생 준비 뒤에는 기기 방향 센서에 따라 회전합니다. 로컬 이미지·영상은 회전 정보를 반영한 실제 비율로 시작합니다. 방향 전환과 갤럭시 폴드 접기·펼치기에서는 재생 화면을 새로 만들지 않으며, 잠금화면과 오버레이 사이를 인계할 때는 세션의 마지막 로컬·YouTube 재생 위치에서 이어보기를 시도합니다. 공식 YouTube 플레이어의 네트워크·자동재생·탐색 제한은 그대로 적용됩니다.

필수 접근이 모두 준비되기 전에는 새 알람, 편집, 전체화면 테스트를 사용할 수 없습니다. 누락된 접근과 설정 버튼은 알람 목록 위에 표시되고 설정 화면에서 돌아오면 즉시 갱신됩니다. 기존 알람 목록과 최근 콘텐츠는 계속 열람할 수 있습니다.

CLI에서는 `./gradlew test assembleDebug`(Windows: `gradlew.bat test assembleDebug`)로 확인할 수 있습니다.
